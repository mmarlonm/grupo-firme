## ✅ Cómo Usar

Una vez agregues las fotos, el código las buscará automáticamente en:
- `/images/hero.jpg`
- `/images/gallery-1.jpg`, etc.
- `/images/album-1.jpg`, etc.

No necesitas editar código, solo coloca las imágenes con estos nombres.

**Formatos soportados:** JPG, PNG, WebP
**Tamaño máximo recomendado:** 2MB por imagen
